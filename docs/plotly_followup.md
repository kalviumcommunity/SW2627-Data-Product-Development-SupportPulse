# Plotly Interactive Dashboard Documentation

## Project

SupportPulse – Interactive Dashboard using Plotly

---

# Interactive Features Implemented

## 1. Custom Hover Tooltips

Custom hover tooltips were added to all interactive charts.

Displayed information includes:

- Date
- Revenue
- Customer Count
- Region
- Monthly Spend
- Transaction Amount

### Benefits

- Provides additional details without cluttering the dashboard.
- Allows users to inspect exact values.
- Improves user experience.

---

## 2. Dropdown Menu

A dropdown menu was implemented for the Churn Trend chart.

Users can switch between:

- Actual Churn
- Predicted Churn

### Benefits

- Reduces dashboard clutter.
- Allows comparison using a single visualization.
- Improves dashboard usability.

---

## 3. Zoom and Pan

Interactive Plotly charts support:

- Zoom
- Pan
- Double-click Reset
- Box Select

### Benefits

Users can investigate specific time periods or customer segments without changing the dashboard layout.

---

## 4. Range Slider

The Monthly Customer Trend chart includes a date range slider.

Users can:

- View the complete timeline
- Focus on shorter time periods
- Quickly navigate through historical data

---

## 5. Range Selector Buttons

The dashboard provides quick date filters.

Available options:

- Last 3 Months
- Last 6 Months
- All Data

These buttons simplify time-based analysis.

---

# Business Value

Interactive dashboards allow decision makers to:

- Explore customer behaviour
- Analyse revenue trends
- Investigate churn patterns
- Identify high-value customers
- Discover regional performance

without requiring multiple static reports.

---

# Conclusion

Plotly significantly improves dashboard usability through interactive exploration, custom tooltips, dynamic filtering, and smooth navigation. These features help stakeholders analyse business metrics more efficiently and make faster data-driven decisions.
